# Load a CSV Dataset - AI & ML Track

## Objective
The objective of this project is to learn how to import real-world tabular data for machine learning workflows using Python and Pandas.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Deliverables
- Loaded CSV dataset
- First five and last five records displayed
- Dataset source link

## Dataset Information
The dataset used in this project is the Titanic Dataset, which provides information on the passengers aboard the Titanic.

## Code execution
The dataset was loaded into a Pandas DataFrame using `pd.read_csv()`, and the `head()` and `tail()` functions were used to verify the correct loading of the data. 

## Conclusion
The CSV dataset was successfully loaded, and data integrity was verified by inspecting the initial and final records.
